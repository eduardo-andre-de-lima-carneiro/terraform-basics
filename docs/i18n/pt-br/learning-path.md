# Trilha de Aprendizado

Este curso foi pensado para alunos que estão começando com Terraform ou migrando de mudanças manuais na nuvem.

1. Leia o Capítulo 1 para construir o modelo mental certo.
2. Conclua o Capítulo 2 e verifique o Terraform localmente com `terraform version`.
3. Percorra o Capítulo 3 em um diretório de prática descartável.
4. Repita os exercícios até o fluxo de trabalho parecer previsível.
5. Use o Capítulo 4 para a plataforma da sua equipe e o Capítulo 5 para o seu editor ou IDE.

Cada seção deve combinar uma explicação curta, um exemplo de comando, a saída ou o resultado esperado e um pequeno exercício.
