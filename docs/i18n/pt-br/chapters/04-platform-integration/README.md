# Capítulo 4: Integração com Plataformas

Plataformas hospedadas executam o Terraform para uma equipe: elas armazenam o state, rodam planos em pull requests, condicionam os applies a uma aprovação e mantêm as credenciais em um gerenciador de segredos. Os comandos locais permanecem os mesmos; a plataforma adiciona identidade, permissões, automação e trilha de auditoria.
