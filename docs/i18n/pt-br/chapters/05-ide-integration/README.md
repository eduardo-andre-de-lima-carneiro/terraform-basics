# Capítulo 5: Integração com IDE e Editores

A maior parte do trabalho diário com Terraform acontece dentro de um editor de código ou IDE. Os comandos dos capítulos anteriores continuam rodando por baixo; o editor adiciona uma camada visual para escrever HCL, validar, formatar, navegar entre módulos e revisar planos. Este capítulo explica primeiro as ideias compartilhadas e depois mostra como elas aparecem no Visual Studio Code, nas IDEs da JetBrains e no Vim ou Neovim, seguidos por um breve tour por outros editores, uma nota sobre fluxos de trabalho assistidos por IA e como configurar o language server e a formatação.
