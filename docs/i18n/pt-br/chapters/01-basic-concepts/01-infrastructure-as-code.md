# 1.1 Infraestrutura como Código

A infraestrutura como código descreve servidores, redes e serviços em arquivos de texto versionados e revisados. Ela permite que uma equipe recrie um ambiente, compare revisões, identifique autores e altere a infraestrutura sem depender da memória ou de cliques manuais.

## O problema que ela resolve

Sem infraestrutura como código, a configuração real vive apenas em um console e na cabeça de algumas pessoas. Reconstruí-la ou auditá-la vira adivinhação. Em vez disso, o Terraform mantém a configuração pretendida em arquivos estruturados.

## Prática

Anote cada passo manual que você daria para criar um pequeno resource no console da sua nuvem. Essa lista é o valor que a infraestrutura como código oferece: ela transforma esses passos em um arquivo que você pode revisar, repetir e reverter.
