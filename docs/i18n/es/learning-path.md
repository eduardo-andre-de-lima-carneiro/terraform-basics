# Ruta de aprendizaje

Este curso está pensado para quienes empiezan con Terraform o vienen de hacer cambios manuales en la nube.

1. Lee el Capítulo 1 para construir el modelo mental adecuado.
2. Completa el Capítulo 2 y verifica Terraform en local con `terraform version`.
3. Trabaja el Capítulo 3 en un directorio de práctica desechable.
4. Repite los ejercicios hasta que el flujo de trabajo te resulte predecible.
5. Usa el Capítulo 4 para la plataforma de tu equipo y el Capítulo 5 para tu editor o IDE.

Cada sección debe combinar una explicación breve, un ejemplo de comando, la salida o el resultado esperado y un pequeño ejercicio.
