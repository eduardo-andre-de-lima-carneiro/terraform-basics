# Capítulo 4: Integración con plataformas

Las plataformas gestionadas ejecutan Terraform en nombre de un equipo: almacenan el state, ejecutan planes en los pull requests, restringen los applies tras una aprobación y guardan las credenciales en un gestor de secretos. Los comandos locales no cambian; la plataforma añade identidad, permisos, automatización y un registro de auditoría.
