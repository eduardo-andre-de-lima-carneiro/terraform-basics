# Capítulo 5: Integración con IDE y editores

La mayor parte del trabajo diario con Terraform ocurre dentro de un editor de código o un IDE. Los comandos de los capítulos anteriores siguen ejecutándose por debajo; el editor añade una capa visual para redactar HCL, validar, formatear, navegar entre módulos y revisar planes. Este capítulo explica primero las ideas comunes y luego muestra cómo aparecen en Visual Studio Code, los IDE de JetBrains y Vim o Neovim, seguido de un breve recorrido por otros editores, una nota sobre los flujos de trabajo asistidos por IA y cómo configurar el language server y el formato.
