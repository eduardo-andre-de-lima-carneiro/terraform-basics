# Chapitre 5 : intégration aux IDE et éditeurs

La majeure partie du travail Terraform au quotidien se fait dans un éditeur de code ou un IDE. Les commandes des chapitres précédents s'exécutent toujours en dessous ; l'éditeur ajoute une couche visuelle pour rédiger du HCL, valider, formater, naviguer entre les modules et relire les plans. Ce chapitre explique d'abord les idées communes, puis montre comment elles apparaissent dans Visual Studio Code, les IDE JetBrains, et Vim ou Neovim, suivi d'un bref tour d'autres éditeurs, d'une note sur les workflows assistés par IA, et de la façon de configurer le serveur de langage et le formatage.
