# Chapitre 4 : intégration aux plateformes

Les plateformes hébergées exécutent Terraform pour une équipe : elles stockent le state, exécutent les plans sur les pull requests, verrouillent les applies derrière une approbation, et gardent les identifiants dans un gestionnaire de secrets. Les commandes locales restent les mêmes ; la plateforme ajoute l'identité, les permissions, l'automatisation et une piste d'audit.
