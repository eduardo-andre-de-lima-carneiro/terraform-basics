# Parcours d'apprentissage

Ce cours est conçu pour les apprenants qui débutent avec Terraform ou qui migrent depuis des changements cloud manuels.

1. Lisez le chapitre 1 pour construire le bon modèle mental.
2. Réalisez le chapitre 2 et vérifiez Terraform en local avec `terraform version`.
3. Parcourez le chapitre 3 dans un répertoire de pratique jetable.
4. Répétez les exercices jusqu'à ce que le workflow devienne prévisible.
5. Utilisez le chapitre 4 pour la plateforme de votre équipe et le chapitre 5 pour votre éditeur ou IDE.

Chaque section doit combiner une explication courte, un exemple de commande, la sortie ou le résultat attendu, et un petit exercice.
