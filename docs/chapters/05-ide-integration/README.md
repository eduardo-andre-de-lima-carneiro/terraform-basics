# Chapter 5: IDE and Editor Integration

Most day-to-day Terraform work happens inside a code editor or IDE. The commands from earlier chapters still run underneath; the editor adds a visual layer for authoring HCL, validation, formatting, navigation between modules, and plan review. This chapter explains the shared ideas first, then shows how they appear in Visual Studio Code, the JetBrains IDEs, and Vim or Neovim, followed by a short tour of other editors, a note on AI-assisted workflows, and how to configure the language server and formatting.
