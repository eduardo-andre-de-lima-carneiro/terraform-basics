# Learning Path

This course is designed for learners who are new to Terraform or moving from manual cloud changes.

1. Read Chapter 1 to build the right mental model.
2. Complete Chapter 2 and verify Terraform locally with `terraform version`.
3. Work through Chapter 3 in a disposable practice directory.
4. Repeat the exercises until the workflow feels predictable.
5. Use Chapter 4 for your team's platform and Chapter 5 for your editor or IDE.

Each section should combine a short explanation, a command example, expected output or result, and a small exercise.
